# 3D Printable Box for Somfy Matter Remote

These are the models I used for the box I have my remote project in.

Print the top and bottom with the large flat side on the print bed. No supports are required. The "button holder" is a small flat piece that can be glued to the bottom of the button and then screwed to the top of the case, holding the button in place so it can be pushed.

To attach things you'll need...

- ESP32: 4 x M2.6*6 screws
- CC1101: 2 x M2.6*6 screws
- Button holder: 2 x M2.6*6 screws
- Box top to box bottom: 4 x M2.6*10 screws

For the LED I just pushed it through the hole and hot glued it in.

The ESP32 and CC1101 mount UPSIDE DOWN in the box so the header pins point up to the inside of the box - easy access to plug things together and assemble.

You can potentially fudge the screw sizes given it's just plastic. There wasn't science behind the sizes I picked, I just happened to have them. [This is the set of screws I have.](https://amzn.to/4avfLJj)
