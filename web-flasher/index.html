Flash the Somfy Awning Matter Remote

This installs the firmware onto an Elegoo ESP32 DevKit V1 directly from your browser. No build tools or command line are needed.

Use a desktop version of Chrome or Edge. This page relies on Web Serial, which Firefox, Safari, and mobile browsers do not support.
  1. Connect the ESP32 to this computer with a USB data cable.
  2. Pick the button below that matches what you are doing.
  3. Choose the ESP32's serial port when the browser asks.
  4. Wait for the install to finish.

First-Time Install

Use this on a new or blank board. It writes the complete image, including the bootloader, so it works on hardware that has never run this firmware.

This erases saved data. If the device is already paired, you will have to re-enter Wi-Fi credentials, add it to Google Home again, and re-pair it with the awning motor. Use Update Firmware instead to keep those.

Your browser does not support Web Serial. Use desktop Chrome or Edge. Serial access was blocked. Allow it and reload the page.

Afterward the device hosts an Awning-Setup-XXXX Wi-Fi network for configuration. See the commissioning guide for the full setup walkthrough.

Update Firmware

Use this on a device that already runs this firmware. It writes only the program, leaving stored settings alone, so the Wi-Fi credentials, the Google Home pairing, and the awning pairing all survive. Nothing needs setting up again afterward.

The browser will ask whether to erase the device first. Leave the Erase device box unchecked, or the pairings are lost and there is no point using this path. This also will not work on a blank board, because it does not write a bootloader; if the device does not start up afterward, run the first-time install above.

Your browser does not support Web Serial. Use desktop Chrome or Edge. Serial access was blocked. Allow it and reload the page.
